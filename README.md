# Pixel Palette Studio

Plugin para Blockbench com presets de brilho metálico e flipbook de pixel art.

## Instalação por URL

No Blockbench, abra **File → Plugins** e escolha instalar por URL:

`https://raw.githubusercontent.com/matheuz55peri-tech/Pixel-Palette-Studio/main/pixel_palette_flipbook_studio.js`

O arquivo registra o ID `pixel_palette_flipbook_studio`. Não renomeie a cópia se instalar localmente.

## Atualizações

Verificação silenciosa ao iniciar e **Tools → Pixel Palette Studio · Verificar atualizações**. Instalações por URL podem ser recarregadas com confirmação, caso a API do Blockbench suporte reload; instalações locais podem exigir reinstalação. A API não foi testada no aplicativo desktop.

Para publicar versões novas, atualize o valor de `CURRENT_VERSION` no .js e `version` no `version.json`. Mantenha o URL e ID estáveis.
